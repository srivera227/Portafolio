Sistema de Gestión de Turnos GTR

Sistema web desarrollado para apoyar la gestión operativa de personal de conducción de trenes y tranvía, operadores de conducción y maniobristas. Centraliza solicitudes, aplica reglas de validación y facilita el seguimiento de cada caso.

PythonDjangoDjango REST FrameworkPostgreSQLAPI Rest HTML / CSS / JavaScriptAzure App Service

Procesos que se automatizan

El flujo general desde el registro de información hasta su validación y consulta.

Registro de solicitud

Validación automática

El sistema verifica datos y reglas definidas para el tipo de solicitud.

Revisión y respuesta

El responsable consulta el caso y registra una aprobación, rechazo o ajuste.

Seguimiento
