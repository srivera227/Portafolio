Analytix

Agente de IA orientado a consultas SQL y Business Intelligence. Permite seleccionar tablas de una base de datos, analizar su estructura y generar consultas de lectura y dashboards a partir del contexto disponible.

PythonDjangoPostgreSQLSQLAnthropic APIHTML / CSS / JavaScript
Mockups de demostración, no son capturas reales. Antes de publicar, reemplázalos por pantallas reales sin credenciales, datos personales ni información sensible.

Funcionalidades principales

Componentes y capacidades implementadas para apoyar el flujo de trabajo de los usuarios.

⌕

Exploración de bases de datos

Conexión a una base de datos activa y selección de tablas para delimitar el contexto de análisis.

▤

Análisis de estructura

Inspección de columnas, tipos de datos y características de las tablas seleccionadas.

✧

Asistencia con IA

Interpretación de preguntas en lenguaje natural y apoyo en la generación de consultas SQL.

⌘

Validación de consultas

Enfoque de consultas de solo lectura para reducir el riesgo de operaciones que modifiquen datos.

▥

Generación de dashboards

Creación de configuraciones de visualización a partir de la estructura y los datos disponibles.

↻

Persistencia y consulta

Almacenamiento de la configuración del dashboard para volver a consultarlo y renderizar sus widgets.

Procesos que se automatizan

El flujo general desde el registro de información hasta su validación y consulta.

Conexión

Se identifica y activa la conexión de base de datos que se utilizará.

Selección de contexto

El usuario elige las tablas que serán analizadas por el agente.

Análisis y generación

El sistema perfila la estructura y solicita a la IA propuestas de SQL y visualizaciones.

Validación y visualización

Las consultas se validan y los resultados se presentan mediante widgets.
